# Conventions

The written conventions for the memory architecture. Each one is short, plain,
and about a single subject, so a session can read the one it needs instead of
the whole set.

- [Card discipline](card-discipline.md): what a memory card holds, how a card
  is created, why promotion is append-only, and what provenance a card
  carries.

Conventions describe practice, not machinery. The tooling that supports them
lives in `../tools/`, and the worked examples of the card shape live in
`../examples/`.

The floor applies here as it does everywhere in this repository: no em dashes,
no ellipses, plain vocabulary. The linter in continuous integration enforces
that mechanically.
