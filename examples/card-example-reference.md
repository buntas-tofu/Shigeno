# Synthetic sample: the reference card

This card is an example of the format. The artifact it names does not exist.

The example evaluation sheet carries its scoring rubric on the same page as
the scores it produced. The rubric names what each band means, the sample size
behind each figure, and what would change the figure. A reader therefore does
not need the run that produced a score in order to read the score.

**Why this is a reference card.** The card points at an artifact and says what
the artifact is for, which is the job of a reference card. It does not restate
the rubric, because the artifact is the authority for its own contents and a
copy of it here would drift.

**How to apply.** When quoting a figure from the sheet, quote the rubric line
with it, including the sample size and the status note. A figure that leaves
the sheet without its rubric reads as a stronger claim than the sheet makes.
