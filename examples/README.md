# Examples

Worked examples of the memory card shape described in
[card discipline](../conventions/card-discipline.md).

Every card here is synthetic. The names, hosts, dates, and figures are
invented to show the format, they describe no real system, and they are not
facts. Nothing in this folder is promoted memory and nothing in it should be
cited as if it were.

Three shapes are shown:

- `card-example-durable-fact.md`, the everyday card: one durable fact, stated
  in the description line, with the reasoning and the application in the body.
- `card-example-supersession.md`, the correction: a new card that replaces an
  older one, with both left in place.
- `card-example-reference.md`, a reference card: where a fact came from and
  what it is usable for.
